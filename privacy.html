Privacy Policy

Last updated: October 27, 2026

Who this app is for

Budget Tracker is a personal tool used only by its owner. It does not offer accounts or services to anyone else.

What data it accesses

With the owner's permission, the app uses the Gmail API to read bank and card alert emails, extract the transaction date, merchant, and amount, apply a label to processed emails, and move processed alert emails older than 90 days to Trash. It does not send email, and it does not read or store other emails.

How data is stored

Extracted transactions are stored only in a database on the owner's own computer. Access credentials are stored in the macOS Keychain.

Sharing

No data is sold, shared with third parties, or used for advertising. Data obtained through Google APIs is used only to provide the budgeting features described above.

Google API Services User Data Policy

Budget Tracker's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the local database removes all stored transaction data.
